MadrasahOS

GitHub

Full-stack bilingual (Arabic + English) school management SaaS for a 40-year-old Lagos Islamic institution with 1,000+ students. Role-based portals for Admin, Teachers, and Students. Handles result management, bilingual PDF reports, Paystack fee collection, WhatsApp notifications via Twilio, and Claude AI smart summaries. Designed for multi-tenant SaaS expansion. Built solo, end to end.

Next.js 14 TypeScript Supabase shadcn/ui NextAuth.js Claude AI Paystack next-intl Twilio
The Problem

INSAIS — a 40-year-old Lagos Islamic school with 1,000+ students — was running entirely on paper. No digital records, no result system, no fee tracking. Staff were manually writing report cards and losing student data across terms. The institution had no digital presence and no way to communicate with parents at scale.

The Build

Built a fully bilingual SaaS platform with role-based portals for Admins, Teachers, and Students using Next.js 14 App Router and Supabase for real-time data and row-level security. next-intl handles true RTL Arabic support. Paystack collects fees, Twilio sends WhatsApp notifications to parents, and Claude AI powers smart result summaries. Designed from day one for multi-tenant SaaS scale beyond this first institution.

OfficialValue Exchange

Live

Live crypto and gift card trading platform for the Nigerian market. A zero-dependency 9-page SPA with GSAP page transitions, CoinGecko live prices in NGN with production CORS fallback, and a Firebase-backed admin panel with SHA-256 password hashing for trade verification. No frameworks — vanilla all the way through.

Vanilla JS Firebase CoinGecko API GSAP HTML/CSS
The Problem

The client ran a crypto and gift card trading operation manually over WhatsApp. Every trade meant switching apps, checking rates by hand, and tracking payments in a notes app. The process was slow, error-prone, and impossible to scale.

The Build

Built without any framework on purpose. The client's hosting situation made a lightweight Vanilla JS build the right call. Firebase Realtime Database handles the live order book. CoinGecko API feeds live crypto prices in NGN, with a production CORS fallback so rates never go stale. The admin panel uses SHA-256 password hashing and lets the team verify gift card uploads and confirm payouts without touching the codebase. Brief to handoff in three weeks.

ORDA

Live GitHub

A trading journal and behavioural intelligence SaaS for retail traders. Tracks trades, performance metrics, psychology, and drawdown in real time. Interactive dashboards with Recharts for P&L analysis, win rate, and risk metrics. Subscription-based access via Paystack with native NGN billing — no USD friction for Nigerian traders.

React TypeScript Vite Tailwind CSS Supabase Recharts Paystack
The Problem

Most traders track what they traded, not why. Spreadsheet journals are tedious and don't surface patterns. The gap between knowing what to do and actually doing it under live market pressure is a behavioural problem, not an informational one.

The Build

Built on React + TypeScript with Vite for fast development iteration and Recharts for the analytics layer. Trade entries include a mandatory "mindset note" field, and the system categorises these over time to surface recurring emotional triggers and drawdown patterns. Paystack handles subscription billing in NGN natively, removing the friction Nigerian traders face with USD-only SaaS tools.

The Bridal Fix

Live GitHub

Nigerian bridal emergency kit e-commerce platform where brides order curated wedding day essentials for nationwide delivery before their big day. Sanity.io CMS for product management, Paystack checkout, Brevo transactional emails, and Framer Motion for a premium product experience.

Next.js 14 TypeScript Sanity.io Paystack Framer Motion Brevo
The Problem

Nigerian brides have no reliable source for curated wedding day emergency kits — the small but critical items that get forgotten on the day. The client wanted a premium e-commerce experience that matched the emotional weight of the purchase and handled nationwide delivery cleanly.

The Build

Built on Next.js 14 with Sanity.io as the CMS so the client can manage products without touching code. Paystack handles checkout, and Brevo fires order confirmation and shipping emails automatically. Framer Motion gives the product pages the premium feel the brand needed — smooth reveals and transitions that match the luxury positioning.
